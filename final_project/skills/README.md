# skills

Reusable instructions the agent can run on this vault (one folder per skill, each with a SKILL.md).

Planned skills (future work):
- `capture/`: save a note, link or chat output into `0_inbox/` with date and source.
- `weekly-review/`: go through the inbox and propose where each item belongs.
- `distill/`: summarize a note into its key points (progressive summarization).
- `express/`: turn notes from a project into a draft (report, slides, post).
