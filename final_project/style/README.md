# style

How notes are written, so every note looks the same and the agent can read it.

Initial rules:
- File names: `yyyy-mm-dd-short-title.md`, lowercase, hyphens.
- Every note starts with a front matter: `title`, `date`, `source`, `tags`, `status`.
- Language: English for course material, Spanish allowed for personal notes.
- Highlights in **bold**, the one-line summary at the top.
