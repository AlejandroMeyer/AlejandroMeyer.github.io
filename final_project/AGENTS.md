# AGENTS.md

Instructions for any AI agent that works in this second brain.

## What this folder is

A personal knowledge vault organized with the PARA method. Read `README.md` first.

## Rules

1. New information always goes to `0_inbox/` unless I say where it belongs.
2. Never delete a note. Move inactive notes to `4_archive/`.
3. Follow the note format in `style/`.
4. Before creating a skill, check `skills/` for one that already does it.
5. When unsure where a note belongs, ask: "Is it a project (deadline), an area (ongoing), or a resource (interest)?"

## Typical tasks

- "Capture this": save it in `0_inbox/` with date and source.
- "Weekly review": list inbox items and propose a PARA folder for each one.
- "Summarize project X": read `1_projects/X/` and write a short status.
